# Поиск сообщений по истории чатов

Гибридный семантический поиск по экспортам корпоративных чатов с генерацией ответов. Сообщения разбиваются на чанки и индексируются в Qdrant dense- и sparse-векторами; поиск объединяет оба вектора, реранжирует результаты на уровне сообщений, а локальная LLM формирует ответ по найденному контексту.

Проект вырос из решения из всероссийского хакатона «ИТ Академия Samsung 2026». Сервисы `index` и `search` реализуют фиксированные контракты хакатона, всё остальное добавлено после него.

## Как запустить

### Требования

- Docker и Docker Compose
- (опционально) [Ollama](https://ollama.com) на хосте - нужен только для генерации ответов. Сам поиск работает без него.

### Запуск

```bash
docker compose up --build
```

Затем открой веб-интерфейс: **http://localhost:8090**

При первом старте:
- `ml-service` скачивает модели эмбеддингов и реранка (несколько минут);
- коллекция в Qdrant создаётся автоматически;
- `backend` сам индексирует корпус по умолчанию (`Go Nova`), поэтому поиск заработает, как только закончится индексация.

### Генерация ответов (опционально)

Ответы формирует локальная LLM через Ollama на хосте.

Установка Ollama:

```bash
# macOS (Homebrew)
brew install ollama

# Linux
curl -fsSL https://ollama.com/install.sh | sh
```

Либо скачай приложение с https://ollama.com/download (macOS / Windows).

Запусти сервер (приложение с сайта делает это само; для brew/curl - `ollama serve` или `brew services start ollama`), затем скачай модель:

```bash
ollama pull qwen2.5:3b-instruct    # ~1.9 ГБ, один раз
```

Ollama должен слушать `localhost:11434`. Модель и адрес меняются переменными `LLM_MODEL` и `LLM_URL`.



## Сервисы

| Сервис | Порт | Назначение |
|---|---|---|
| **web-ui** | 8090 | Веб-клиент который ищит сообщение через поиск. |
| **backend** | 8005 | API поверх пайплайна: поиск, генерация ответа, управление активным чатом, загрузка чатов. |
| **search** | 8002 | Гибридный поиск: dense + sparse retrieval со слиянием DBSF и реранком на уровне сообщений. Возвращает `message_ids`. Контрактный сервис хакатона. |
| **orchestrator** | 8004 | Индексация: собирает чанки (`index`), dense-вектора (`ml-service`) и sparse (`index`) и пишет точки в Qdrant. |
| **ml-service** | 8003 | Локальный ML: dense-эмбеддинги, реранкер и генерация ответов через LLM. Заменяет внешние API организаторов. |
| **index** | 8001 | Строит чанки из сообщений и считает sparse-вектора (ключевые слова, IDF). Контрактный сервис хакатона. |
| **qdrant** | 6333 | Векторная БД: хранит чанки с dense- и sparse-векторами. |

Внутри Docker-сети все сервисы слушают порт `8000` (Qdrant - `6333`); в таблице указан порт, проброшенный на хост.
